Travel Landing Page

A modern and responsive travel landing page designed to showcase travel destinations in an attractive and engaging way.

Features

- Modern and clean user interface
- Responsive design for different screen sizes
- Attractive hero section with travel imagery
- Gradient background and visual overlays
- Well-structured layout using HTML and CSS
- Smooth hover effects and interactive elements

Technologies Used

- HTML5
- CSS3
- Flexbox
- Responsive Design
- CSS Gradients
- CSS Hover Effects
Project Goal

The goal of this project was to practice building a responsive landing page and improve my skills in layout design, positioning, colors, backgrounds, and responsive web design.
